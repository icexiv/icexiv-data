# Excel 表格资源

游戏的表格资源位于包内的 `exd/` 类别，由 EXL 清单、EXH 表头和 EXD 数据页组成。它们不是安装目录中独立存在的文件，需要先从 SqPack 提取。

## 文件组织

以下为逻辑路径示意，表名按查找用的小写形式表示：

```text
exd/
├── root.exl                 表名清单
├── item.exh                 Item 表的结构、分页和语言
├── item_0_en.exd            起始行 ID 为 0 的英语页
├── item_0_ja.exd            同一页的日语版本
├── item_{start}_en.exd      其他数据页
├── {sheet}.exh              其他表
└── {sheet}_{start}.exd      无语言后缀的数据页
```

分页起点和可用语言以对应 EXH 的声明为准，不是每张表都有上图中的所有文件。

## EXL：表名清单

入口为 `exd/root.exl`，是逗号分隔的文本：

- 首行为 `EXLT` 标识和版本号。
- 后续每行为表名和表 ID；`-1` 表示没有可用的表 ID。
- 从表名构造 `exd/{sheet}.exh`，不能用表 ID 当作文件名。

表 ID 与 EXD 内的行 ID 是不同层级。`show_root_exl` 示例只读取清单，按表名路径展示树状结构；表名末尾的数字保留，不作为分页编号拆分。

## EXH：表的结构

每张表有一个 EXH，描述其数据页的共同布局：

| 信息 | 用途 |
| --- | --- |
| 列类型、偏移 | 解码每列的值 |
| 固定数据长度 | 划分行中的固定数据和变长字符串 |
| 行变体 | 普通行或子行 |
| 分页范围 | 选择包含目标行 ID 的页 |
| 语言列表 | 构造对应语言的数据页路径 |

EXH 不包含列名、业务含义或跨表引用关系。这些需要额外的 schema，不能仅凭列类型判断某个整数引用了哪张表。

## EXD：分页与语言

```text
exd/{sheet}_{page-start}{language-suffix}.exd
```

`page-start` 是该页覆盖范围的起始行 ID，不是页序号。EXH 的每个分页项描述 `[start, start + count)`；范围中不一定每个 ID 都有行，页与页之间也可以有空隙。

同一个分页起点可以有多个语言版本，语言后缀如下：

| 语言 | 后缀 |
| --- | --- |
| 无语言 | 无 |
| 日语 | `_ja` |
| 英语 | `_en` |
| 德语 | `_de` |
| 法语 | `_fr` |
| 简体中文 | `_chs` |
| 繁体中文 | `_cht` |
| 韩语 | `_ko` |

语言列表取决于表和客户端数据；不能假设每张表都有英语或所有客户端包含全部语言。页内包含整行数据，而不只是该语言的文本列。

## 行与子行

- **普通行**：以 `row_id` 标识，页内索引将 ID 映射到行数据。
- **子行**：以 `(row_id, subrow_id)` 标识；页内索引先找到父行记录，再按其中存储的子行 ID 查找。

行 ID 和子行 ID 都不必连续，也不是文件中的物理序号。行包含固定宽度字段和变长字符串；字符串通过偏移引用，可能含有 SeString 控制内容，不能一律视为普通 UTF-8 文本。

读取顺序为：

```text
root.exl → 表名 → EXH → 分页、语言 → EXD → 行/子行 → 列值
```

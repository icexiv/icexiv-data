# ENVB 容器实读证据

样本来自 Windows 数据档案 `2026.11.03.0000.0000`，路径
`bgcommon/env/global/ffxiv_genv/genv_est_e1/genv_e1_hou/genv_e1h1.envb`。
用 `local_sqpack` 解包得到 26,111 字节；SHA-256
`510d1c33ea2a449386551f675bcdc09574c549b96670e3527b2ca253d8c27b2d`。
观察值为解包后绝对字节位置；数值为小端。

- `ENVB` 在 0，文件长度在 4，环境数在 8，`ENVS` 在 12。版本字段在
  20，区段偏移字段在 24，值为 16；区段表始于 `20 + 16 = 36`。
- 首区段从 36 起：四个 u32 为 `96, 10, 1, 4528`；轨道表在
  `36 + 96`，footer 在 `36 + 4528`。footer 前三项解码为
  `86400.0, 51, 1.0`。
- 从首区段找到编号 0 的轨道后，用轨道条目自身作为偏移基准定位关键帧
  偏移表；再用该表起点作为单条偏移基准，首记录落在 3576。颜色相对
  基准为记录起点 3576；三条偏移为 52、60、68。`+44` 的
  `30 30 37 56` 为版本标记 `007V`，不属于颜色；首颜色在 `+52`，
  为 `00 00 00 ff`，紧接强度 `0.1`。编号 2 的首帧在 2584，
  颜色偏移 28、36 以本记录开头为基准。
- 编号 13 的首帧在 1196。`+32` 为 `007V`，后续字段以四字节为单位；
  `+36/+40/+44/+48` 分别为 `0.2/-50.0/0.25/100.0`。
  `+4/+80` 为 `88/96`，指向以记录为基准的两组颜色记录。

本样本遍历得到六区段、62 轨、379 个关键帧。区段和轨道的语义名称参考
同一档案经 Physis 离线观察的比对结果；不作独立洁净室声明，也不引入
Physis 为本库依赖。库的单元测试使用人工构造的小型字节夹具，不包含原版
资源。此证据不建立天气编号绑定、运行态相位选取或 UE 渲染等价性。
